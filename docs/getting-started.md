# Getting started with SmiCalc

## Use it now

The easiest option is [Use online next to your language](../README.md#choose-your-language).
You do not need a GitHub account or any installation.

## Use a downloaded file

1. Select **Download** next to your language on the [SmiCalc page](../README.md#choose-your-language).
2. Find the `.html` file in Downloads and double-click it.
3. If your computer asks which app to use, select a web browser such as Chrome,
   Edge, Firefox or Safari. You can also drag the file into a browser window.

For the all-language ZIP, use your computer's **Extract** or **Unzip** command first.
The `START-HERE.txt` file lists all languages and filenames. Open just the language
you need; you do not need to download the source-code archive or use GitHub's Code menu.

The HTML contains the calculator's code, data and styling. Keep the file anywhere
convenient. The calculators work offline with manual material selection. External
links require internet; the hosted AI Material Selector requires an approved website.
For AI-assisted selection, use the online version or request approval for your site.

On phones and tablets, use the online version if your device previews the downloaded
file instead of opening it as a working app.

## If something looks wrong

- **You see code instead of the calculator:** open the downloaded file in a web browser,
  not a text editor. Check that its filename still ends in `.html`.
- **The browser shows the app instead of downloading it:** save the link's target
  as an `.html` file, or use the all-language ZIP.
- **AI Material Selector does not connect in a local file:** this is expected.
  Use manual material selection, or open SmiCalc on smicut.com.
- **You need a different language:** return to the language table and download that edition.

## Get updates

Return to [the download table](../README.md#choose-your-language) for the latest files.
Downloads do not update themselves. Keep a backup before replacing a customized
version; downloading an update does not carry your own edits into the new file.

## Use SmiCalc on your website

You may publish SmiCalc on your company's website, including under your own brand.
Ask whoever manages your website to upload the HTML file and link to it, or embed
it in a page. Review [the customization guide](../REBRANDING.md) first.

For WordPress, give your web developer the HTML file and
[the embedding guide](../wordpress-embed-design-guide.md). The widget can be placed
in a suitable Custom HTML block, but the site's settings must allow its scripts.
Your developer should check the actual theme and mobile layout. Downloading the
file alone does not install it in WordPress.

The calculators can run with manual material selection. To enable the AI Material
Selector on your website, [request approval for the exact website address](../MATERIAL_SELECTOR.md).

## Need help?

Email [info@smicut.se](mailto:info@smicut.se) with your language, browser and a short
description of the problem. For AI website approval, follow the
[Material Selector guide](../MATERIAL_SELECTOR.md).
